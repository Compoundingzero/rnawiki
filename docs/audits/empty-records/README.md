# Empty medicine-class records: triage

Generated by `scripts/inventory/audit-empty-records.ts`. Regenerate with:

```bash
RNAWIKI_INGEST_DATA=<ingest data directory> npx tsx scripts/inventory/audit-empty-records.ts
```

An "empty" record is a canonical record none of whose six statement sections (recorded uses,
mechanism, safety statements, adverse reactions, pharmacokinetics, population statements) rests
on a source. The script reads the database and the label-sections index; it writes nothing to the
database.

## Files

- `medicine-class-triage.ndjson` — one line per empty record in the five medicine-like classes,
  with the bucket it landed in and the evidence behind that decision.
- `class-changes.ndjson` — every canonical record whose entity class changes under rule 5 of
  `lib/inventory/entity-class.ts`, with the stored label-presence facts the rule read.
- `trailing-tokens.json` — every trailing token on a single-substance label name in the index,
  how many distinct stems it trails, and whether the extractor's salt/ester table selects it.
- `summary.json` — counts per class and bucket, the fraction of approved-medicine empties each
  bucket explains, class-change counts by pair, and the salt/ester fallback results.

## Buckets

Tested in this order; the first that applies wins.

1. `SALT_OR_ESTER_LABEL_EXISTS` — no label names the record (by its name, its recorded salt-form
   or INN aliases, or a merged duplicate's name), but exactly one salt, ester or hydrate form of
   the name has its own single-substance label. The fallback refuses an elemental stem and refuses
   when more than one form is on the market alone. In the extractor it also runs only for a row
   with a medicine status: a botanical or supplement row has no salt form, and "Tea" the plant
   must not find "TEA salicylate" (triethanolamine salicylate).
2. `DISCONTINUED_NO_CURRENT_LABEL` — no label under any form. Evidence records whether a
   Drugs@FDA application or a product listing is recorded, so a reader can separate a medicine
   that once had an application from a name that never did.
3. `INGREDIENT_MISCLASSIFIED` — labels exist; every one is a non-prescription product; none
   declares the record as its only active substance; no Drugs@FDA application is recorded. These
   are the four facts entity-class rule 5 reads. Here they come from the index; rule 5 reads them
   from the stored `labelPresence` module and `regulatoryApproval` application number. Rule 5
   applies only to approved statuses; the bucket is reported for the other medicine-like classes
   without changing their class.
4. `EXTRACTOR_MISSED` — a single-substance label carrying at least one read section exists and
   the extractor recorded nothing from it. Handled by the extraction stream.
5. `SINGLE_LABEL_WITHOUT_READ_SECTION` — a single-substance label exists but carries none of the
   sections the extractor reads.
6. `MULTI_SUBSTANCE_LABELS_ONLY` — every label declares the record together with other active
   substances, and rule 5 does not apply because a prescription label or an application is
   recorded. A statement about one substance is not read from such a label.

Buckets 5 and 6 are outside the four the triage set out to fill. They are reported as what they
are rather than forced into one of the four.
