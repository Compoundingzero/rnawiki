My Plan

One plan, in one place, built from the cause of your problem rather than its name. Your plan lives in this browser — there is no account to create and nothing to pay.

If you already have a plan, it will appear here in a moment. It is stored on your own device, so it loads when the page does. If you are reading with JavaScript turned off, this page cannot show it — everything else below works either way.

#How a plan gets built

  1. Name the problem or the goal. Start at Solve, or point to where it hurts if you do not know what it is called.
  2. Find which cause you actually have. Most problems here have several, and the fix is different for each — the same knee pain has a different answer depending on whether the tendon, the joint surface or the hip is driving it. Each protocol opens with a short set of questions that narrows it.
  3. Start the plan. That pulls the movements, the foods and the evidence-ranked compounds for that cause into one list.
  4. Work it, then reassess. Every protocol states how long to give it before you judge it, what "working" looks like, and the point at which the answer is a clinician rather than another supplement.

#Start from something concrete

  • Every problem and goal, with its root causes
  • Point to where it hurts — for pain you cannot name
  • The compound index — if you already know what you are looking at
  • All 171 compounds, A–Z

#What a plan is not

It is not a prescription and not a diagnosis. It is a reading list with an order, built from the same evidence the rest of the site shows you. Prescription and controlled medicines are never added to a plan and never dosed here. How these pages are made →
