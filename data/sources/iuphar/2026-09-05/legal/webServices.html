New REST API

New API - access via API Keys - from late August 2026

We will be updating our REST API in line with changes requiring users to register to access the Guide to Pharmacology. The updated REST API will be accessible with the use of an API Key. Once registration to GtoPdb is available, registered users will be able to contact us to get an API Key. Registration will be available from 18th August 2026, with the implementation of the API Key requirement following in late August, early September.

Overview

This page describes the Guide to PHARMACOLOGY REST API, which provides programmatic access to data in the Guide to PHARMACOLOGY database. The API currently returns data in JSON format. We may extend the range of supported formats in future releases. You can retrieve information on families, targets, genes, ligands, interactions and text annotations.

The GtoPdb REST API base URL (base_url) is https://www.guidetopharmacology.org/services/.

This URL points to the current version of the API. The API will be updated in line with normal database release cycles to support new data types and functionality as required.

Specific services can be accessed by appending the relevant path to the base URL, as shown in the tables below. Optional parameters can be added by appending a question mark (?) to the end of the service URL and separating multiple parameters with an ampersand (&), for example:

https://www.guidetopharmacology.org/services/targets/290/interactions?affinityType=pKi&species=Human.

Python wrapper

pyGtoP provides a Python interface to the web services, which is available on GitHub. Full documentation is available here. The Python wrapper was created as part of another project and is not actively maintained, however please email us with any questions or bug reports and we'll do our best to help.

Interaction web services

ServiceURLParameters
List of interactions{base_url}/interactions

interactionId: a GtoPdb interaction Id

Examples

These are a few example use cases for the web services.

  1. Retrieve the target with Ensembl gene Id ENSG00000097007:
    www.guidetopharmacology.org/services/targets?accession=ENSG00000097007&database=EnsemblGene
  2. Retrieve the target encoded by HGNC gene symbol CATSPER4:
    www.guidetopharmacology.org/services/targets?geneSymbol=CATSPER4
  3. Search for the target with name HER3:
    www.guidetopharmacology.org/services/targets?name=HER3
  4. Find the subunits of 5-HT3AB (target Id 378):
    www.guidetopharmacology.org/services/targets/378/subunits
  5. Find agonists of GPER (target Id 221) with pKi >= 7:
    www.guidetopharmacology.org/services/targets/221/interactions?type=Agonist&affinityType=pKi&affinity=7
  6. Retrieve all the approved drugs:
    www.guidetopharmacology.org/services/ligands?type=Approved
  7. Find synonyms for tamoxifen (ligand Id 1016) :
    www.guidetopharmacology.org/services/ligands/1016/synonyms
  8. Find ligands at least 80% similar to the structure CC(CN(C)C)CN1c2ccccc2Sc2ccccc12:
    www.guidetopharmacology.org/services/ligands/similarity?smiles=CC(CN(C)C)CN1c2ccccc2Sc2ccccc12&similarityGt=0.8
  9. Find ligands with the substructure Nc1cnc(Cl)c(N)n1 and calculated LogP between 0 and 2:
    www.guidetopharmacology.org/services/ligands/substructure?smiles=Nc1cnc(Cl)c(N)n1&logpGt=0&logpLt=2
  10. Find all the pKi interaction data for approved drugs at GPCRs:
    www.guidetopharmacology.org/services/interactions?affinityType=pki&approved=true&targetType=GPCR
  11. Retrieve all diseases with OMIM database ID mapped:
    www.guidetopharmacology.org/services/diseases?database=OMIM
  12. Retrieve all diseases mapped to Disease Ontology ID 6688 (Autoimmune Lymphoproliferative syndrome):
    www.guidetopharmacology.org/services/diseases?database=DOID&accession=6688
  13. Retrieve all targets tagged in database as relevant to immunopharmacology (GtoImmuPdb):
    www.guidetopharmacology.org/services/targets?immuno=true
  14. Retrieve all ligands tagged in database as relevant to immunopharmacology (GtoImmuPdb):
    www.guidetopharmacology.org/services/ligands?type=immuno
  15. Retrieve all interaction data for Plasmodium species P. vivax:
    www.guidetopharmacology.org/services/interactions?species=Pv

HTTP response codes

This is a listing of specific HTTP response error codes which can be returned by the GtoPdb web services and their meanings.

HTTP response codeMeaningDescription
204No contentAn empty page and a 204 no content response usually mean there are no results to display for the given URL (i.e. no data in the requested database table).
303See otherRedirection to an alternative location for the requested data (e.g. the path to a ligand image).
404Not foundEither a resource with that address or an entity such as a ligand with the given identifier cannot be found.
