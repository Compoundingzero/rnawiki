1.1 Source Citation

The user must cite the source when using the Content.
Please refer to the examples below and replace them as appropriate with the actual source name, URL, etc.
If URL links can be used, the URL shown in parentheses may be provided as a hyperlink to the relevant text.

To view PDF files, the Adobe Reader application is required.

Notes on Downloading Information

When downloading information posted on this website, please note the following points;

  • Please limit downloads to the minimum necessary.
  • Bulk, excessive, or frequent downloads that place excessive load on the server are strictly prohibited.
    Automated crawling or download applications are also not permitted. If excessive load caused by such activities is detected, access from specific connections may be restricted.
