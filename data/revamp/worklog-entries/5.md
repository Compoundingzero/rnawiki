**Three defects in the hub set were found and fixed on the way.** (a) Target grouping keyed on the
raw UniProt accession split one protein across species — P35348 (human alpha-1A) and P43140 (rat)
became two hubs with 65% shared compounds — so grouping now keys on the UniProt entry-name prefix,
which is shared across orthologues, and falls back to gene symbol then the raw key
(`target_group_key`). (b) The overlap merge was single-linkage and chained: a ~0.5 edge from the
carbonic anhydrases to ABCB1 and another from ABCB1 to polyphenol oxidase 2 published one page
naming eleven unrelated proteins as one target. It is now complete-linkage — a group joins a
component only when it meets 0.5 Jaccard against every group already in it — and the hub's printed
name and the first protein in its definition are now the same protein (the largest group leads).
(c) Member slugs were derived from display names and 4,567 of 6,124 named no published page
(`/d/k1-03j11k103c` for algeldrate); the build now reads the route map
`data/revamp/identity/page-slugs.csv`, so the hub links and prints exactly what the member page
publishes.

A fifth template change followed from reading the output rather than the measurement: a recorded
name can contain a comma of its own ("PROPAFENONE, (R)-", and the combination page
"Sitagliptin, Metformin"), so a comma-separated list of names was ambiguous. Every name list in the
synthesis and in the measured text now separates with a middle dot. The medians did not move: a
separator is not a word token.
